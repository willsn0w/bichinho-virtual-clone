# Bichinho virtual clone

**▶ Jogue agora: https://willsn0w.github.io/bichinho-virtual-clone/**

Bichinho virtual em tela de LCD pixelada, inspirado nos clones dos anos 90. É um único arquivo HTML: abra o `index.html` no navegador e pronto.

## Funções

- **Comer:** comida, sorvete, peixe ou maçã
- **Luz:** apagar a luz faz ele dormir (com Zzz)
- **Jogos:** LADO (esquerda ou direita) e PULO (desviar das pedras)
- **Injeção:** cura a doença; três doses com ele saudável matam
- **Banheiro:** vaso sanitário quando ele tem vontade, descarga para o cocô no chão
- **Status:** fome, felicidade, idade, peso, disciplina e espécie
- **Disciplina:** bronca quando ele faz birra
- **Atenção:** pisca quando ele precisa de você

50 espécies originais para escolher, cada uma com forma de bebê, criança e adulto.

## Controles

| Botão | Teclado | Ação |
|---|---|---|
| A | A, 1, ← | escolher |
| B | B, 2, Enter, → | confirmar |
| C | C, 3, Esc | voltar |
| RESET | R | apagar e escolher outro bichinho (apertar duas vezes) |
| Dev | D | painel de testes |

Três toques em qualquer botão chocam o ovo na hora.

O progresso fica salvo no `localStorage` do navegador.
